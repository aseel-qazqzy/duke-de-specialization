# Duke University – Python, Bash and SQL Essentials for Data Engineering Specialization

A hands-on learning repository for the [Duke University DE Specialization](https://www.coursera.org/specializations/python-bash-sql-data-engineering-duke) on Coursera.

## Courses

| # | Course | Hours |
|---|--------|-------|
| 1 | Python and Pandas for Data Engineering | 52h |
| 2 | Linux and Bash for Data Engineering | 66h |
| 3 | Scripting with Python and SQL for Data Engineering | 24h |
| 4 | Web Applications and Command-Line Tools for Data Engineering | 44h |

## Repository Structure

```
duke-de-specialization/
├── 01-python-pandas-de/
├── 02-linux-bash-de/
├── 03-scripting-python-sql-de/
└── 04-web-apps-cli-tools-de/
```

Each course folder contains:
- `exercises/` – completed exercises and labs
- `notes/` – key concepts and personal summaries
- `mini-project/` – a small project built using course concepts

## Goals

- Build a strong foundation in Python, Bash, and SQL for data engineering workflows
- Practice every concept hands-on rather than passively watching
- Use this repo as a portfolio of practical DE skills

## Stack

Python · Pandas · Bash · Linux · SQL · Git
